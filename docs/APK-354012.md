## Reproduce the finding

From the repository root, with the local input file path:

```sh
python3 -m vesktop_android inspect '/path/to/Discord_354.12 - Stable.apk'
python3 -m vesktop_android check '/path/to/Discord_354.12 - Stable.apk' --profile compatibility/discord-354012.json
```

Expected: the profile's base fingerprint matches; `check` returns `2` because the input set is incomplete. The full metadata report is in [research/discord-354012-inspection.json](../research/discord-354012-inspection.json). No executable Discord code or extracted resources accompany it.
