# Licensing status

The project licence has not yet been selected. This file is a status notice, not an open-source licence or a grant of rights. The intended development model is open source; that needs an actual licence before public reuse and contributions can rely on it.

Before adopting a licence, review every proposed dependency and distribution path, including the distinct licences of Android patch/loader components. No upstream Vesktop, Vencord, Revenge or Valenced implementation code has been copied into this foundation.

Discord application code, resources, bundles and signing material remain separate from this project's own source. The repository must not contain proprietary APK inputs or repackaged Discord releases. User-side patching does not by itself determine compliance with a licence or terms of service.
